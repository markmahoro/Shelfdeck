## 共用验收方法与材料

- 状态只覆盖合同实际存在的正常、空/无结果、载入、等待/满额、需决定、失败、完成及适用部分结果/过期状态，不为矩阵新造业务状态。短状态、语义色、真实数量和就地原因；不能只靠颜色、无效图标或重复汇总。
- 从正常入口无需工程师讲解完成任务；检查字段校验、操作可达、取消不写入、busy防重复、失败不报成功及实际结果刷新。恢复/重试按正式命令合同，HTTP成功不能代替业务结果。
- 键盘覆盖Tab/Shift+Tab、焦点、Enter条件、Esc与关闭后焦点返回、控件标签和必要播报；busy与危险确认不可绕过，核心操作不依赖hover。
- 1920×1080主视口及受影响页面/弹窗的窄屏实测（如390×844）。旧polish最大化边界不免除新功能的适用窄屏验证；不借此全站重做响应式。保留Formation现有列表结构/列宽/筛选/分页，可用既有受控横向滚动，新增控件和弹窗必须可达、不裁切。
- 真正危险动作显示精确Season/Episode/文件范围及后果，验证取消、busy、失败、成功Receipt和共享材料保护，不波及其他Season/Movie；不以无用安全说明代替确认。
- 沿用卡片、语义色、14px正文/按钮、36px按钮高、6px圆角及同域动作对齐；功能入口只在本节点授权内扩展，不把Formation旧列表保护误解成全面重排许可。
- 先交具体diff与设计，再交同版本实际页面证据。材料含工作项、commit/构建、页面/状态、动作与反馈、截图/轨迹、所依赖Owner事实、测试输出及未测项；区分fixture、真实媒体、代码审查及负责人本人实测。负责人给有范围的结论；单测、代码审查或成功截图不足以UI PASS，后续用户可见diff须重验受影响路径。

当前`ea3d33d16`仅为基础能力，尚无Series界面或UI PASS。此次确认不扩大UI改版、业务合同或生产授权；不需要为此另开一轮UI polish。
