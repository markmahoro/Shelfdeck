# UAT-219 / UAT-239 中文层级与字体验收

## 核实

当前App仅加载Helix样式，旧`styles/theme.css`未导入，不因仓库仍有该文件就认为仍混用字体。真实生产Edge收藏页及详情的标题/标签统一为Noto Sans SC / Microsoft YaHei UI / system-ui栈；详情dt为12px正常字距。仍存在实际差异：收藏架/排序标签10px及0.8px字距，配置标签11px/0.88px，页面标题24px/-0.48px；整理过程标签11px，计划编号9px。UAT-239历史字体修正已核实，标签阶梯由UAT-219继续收敛。

## 克制修正

配置分隔、文件来源阶段、整理过程eyebrow、计划编号、收藏架/排序标签统一使用现有`--text-sm`12px及正常字距；阶段标签取消中文uppercase，并使用现有字重变量。页面标题保持24px、取消负字距，与详情标题一致。未另建字体或设计系统。

## 验证

Web既有56项测试与build通过。真实Edge本地候选：宽屏2552px下标签12px/normal，主标题24px/normal；390×844下收藏页面scrollWidth375、无页面横向溢出，上一页/下一页可操作且第二页从049开始。维护详情390px下dialog宽366px、scrollWidth366，阶段标签和计划编号均12px/normal；实际截图确认中文换行、关闭按钮、阶段和等待动作可读。临时viewport已reset。

仍待统一发布后的生产页面复验，UAT-219/239暂不关闭。两项按239字体基础→219标签收敛→共同验收顺序，无循环等待。
