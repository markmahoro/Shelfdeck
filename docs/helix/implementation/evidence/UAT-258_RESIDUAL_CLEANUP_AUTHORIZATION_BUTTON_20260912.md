# UAT-258 自动清理残留文件授权按钮

2026-09-12。用户要求将收藏架配置的旧输入清理折叠入口改为“自动清理残留文件”授权按钮，并对齐任务“确认全页面 UI polish 需求”的方法。Owner：Admin Web呈现；沿用Arca正式授权API及精确清理范围。

## 实施前交互约定

- 页面标题右侧与新建收藏架并列一个“自动清理残留文件”按钮，按钮内显示真实授权状态；移除原折叠入口、三角形及常驻说明。
- 点击按钮打开授权对话框；授予前展示清理范围和保留范围，已授权时可以撤销，部分授权明确显示当前范围并允许扩展。成功后关闭对话框，按钮显示重新读取的正式状态。
- 读取或提交失败不猜测状态，不发送缺少当前revision的授权；就地提供重试。支持键盘打开、取消、焦点回到入口及窄屏。
- 沿用UAT-256配色：白色#ffffff、底色#f1f4f7、边框#d9e0e7、配置蓝#245ea5、成功绿#26704d、正文#243344，全部复用现有token；正文及按钮14px，按钮36px高/6px圆角，对话框8px圆角。无新增卡片、图标或页面说明层级。
- 用户术语“残留文件”仍仅指现有安全替代的精确旧输入，不扩展为任意目录清扫或退出收藏销毁。SSOT §9.6.5、Beta HB-A.07、Playbook §11.1（用户提供的当前主工作区版本）适用。

## 验收范围

更新既有授权组件回归，验证明确授予/撤销、当前revision、部分授权、读取失败、提交失败及取消；构建后在临时数据的真实Host走查页面、确认范围、提交/重读、键盘及390px窄屏。生产部署与验收独立记录，不以历史UAT-172/256通过覆盖本次UI变更。
