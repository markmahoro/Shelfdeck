## 2. 全局禁区（默认 UI 与面向用户的错误）

下列内容**不得**出现在默认可见的界面文案、任务执行日志默认行、或用户可见的错误 `message` 中：

1. **设计文档锚点**：段落号 `§` 及变体（如 `§7.2.3`）。
2. **仓库路径与源文件名**：如 `docs/design/`、`DESIGN_TASK_CENTER.md`、任意 `REQ_*` / `DESIGN_*` 文件名作为「请用户阅读」的指引。
3. **裸内部枚举/代码键名作为唯一标签**：例如单独展示 `queued`、`executing`、`transcodeConcurrency` 作为主标签；若需排障，须放在**技术详情**（折叠、次要文字或可选开关）中，且主界面仍有中文说明。
4. **未释义 API/字段名片语**：如 `DeleteInfo`、`GetLibraryItem`、仅英文的技术子阶段名作为用户主句（见第 4 节分区域替换规则）。

**允许**：配置项旁以小字、Tooltip 或「高级」区展示与持久化 JSON 一致的字段名，且主标题已为中文释义。

## 3. 术语表（对外用语 SSOT）

以下用语用于**默认 UI**；同一概念勿混用多种说法。


| 概念                       | 推荐用户向用语                                            | 使用场景                                                                                                  |
| ------------------------ | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 任务类型 · 压缩成片体积            | **码率压缩**                                           | 任务中心任务卡片动作说明、入队提示（对应 `actionType === 'transcode'`）                                                    |
| 任务类型 · 更高质量片源（`upgrade`） | **洗版**                                             | 任务卡片、入队提示、侧栏与配置中的该类说明；**禁止**对用户使用「补源」「洗版补源」等含「补源」的用语                                                  |
| 任务类型 · 移除条目              | **从 Emby 删除** / **删除任务**                           | 任务卡片、删除确认                                                                                             |
| 任务执行步骤（通用）               | **预检**、**执行中**、**校验中**、**待信息确认**、**已完成**、**已失败** 等 | 与 `[taskQueue.ts](../../media-desktop/src/taskQueue.ts)` `taskStatusLabelZh` **中文值**一致；状态行默认**仅展示中文** |
| 技术过程（转码管线）               | **转码**、**压制**                                      | 长说明中可用「转码」概括；细述编码过程时可用「压制」一词，但**勿与同屏的「码率压缩」任务类型混为不同产品概念**                                             |
| 英文 Flow                  | **流程**、**步骤** 或具体名（如「删除前检查」）                       | 侧栏、帮助句；避免对用户写「Flow」                                                                                   |
| 编码设备标识（stableKey）        | **编码设备**；展示值可附 `cpu:libx265` 等，但列标题不用「设备键」         | 配置中心编码资源池表格                                                                                           |
| 并发配置                     | **同时进行的码率压缩任务数**；删除/洗版在各自小节为 **同时进行的删除任务数** / **同时进行的洗版任务数**     | 主标签；`transcodeConcurrency` 等键名仅作 Tooltip                                                         |


**模拟数据**：`debugSeed` 等模拟任务标题中的阶段名须与 `taskStatusLabelZh` 中文一致（如「执行中」），不得用英文 `executing`。

**「补源」一词**：仅可出现在**内部设计/架构**文档或代码注释中指 MoviePilot、候选资源、片源到位等技术含义；**默认 UI、执行日志默认行、用户可见错误信息中一律不得出现「补源」**，统一用 **「洗版」** 表达 `upgrade` 任务及相关配置（如重试节奏、等待片源等）的用户向含义。

## 4. 分区域规则

### 4.1 配置中心 · 任务调度与转码

- **页眉/说明**：用一两句话说明本页职责与保存后果；**禁止**「与某 md 对表」「模块一/二/三」及 § 编号。
- **小节标题**：用用户语言（如「任务调度」「删除相关」「转码与临时目录」「洗版」）；未完成能力用「即将支持」或暂不展示占位段落。
- **信息分区**：「任务调度」承载**新任务执行方式**（自动执行 / 手动执行，二选一）、**已观看并打完分后自动创建任务**等全局调度项；**各类型并行上限**放在对应流程小节（删除 / 码率压缩 / 洗版）；**洗版等待片源的重试节奏**放在「洗版」小节，与洗版并发并列。
- **按钮**：如「刷新编码设备探测」「检验转码资源池」——**不带**括号 §。
- **字段标签**：「转码临时根目录」「CPU 参与策略」等——不带 §；并发类字段主标签用中文释义（见第 3 节术语表）。
- **海报墙自动入队等勾选说明**：仅保留业务含义，删除 §。
- **保存与检验（用户心智）**：对用户只区分 **保存配置成功** 与 **保存配置不成功**；检验失败、写入失败、非桌面环境无法检验等，一律归为不成功，句式为 **「保存配置不成功。原因：…」**，原因须为可读中文（可将系统错误如 `spawn EFTYPE` 改写为路径/可执行文件说明）。**保存转码相关配置**在桌面版须先通过环境与资源池检验再写入；成功时可用 **「保存配置成功。」** 等短句。
- **保存后提示**（独立「检验」按钮等）：仍可用结果导向中文；**禁止**「§5.8」类字样。
- **呈现位置、状态拆分与自动清除**：配置中心内保存/检验反馈的**展示槽位**、**专用状态**（与全局底部横幅解耦）、**检验结果与持久化保存**分开展示、**成功提示短时效清除**等，以 `[DESIGN_CONFIG_CENTER_SAVE_FEEDBACK.md](./DESIGN_CONFIG_CENTER_SAVE_FEEDBACK.md)` 为准；本文仍约束**用户可见中文句式与禁区**。

### 4.2 任务中心 · 侧栏与任务卡片

- **侧栏分组**：「可选工具」「维护与排错」等；**禁止**「非 §xx 必选」。
- **任务状态行**：默认仅中文状态；英文 `TaskStatus` 枚举放入「技术详情」或移除。
- **说明段落**：用「各步骤进度（含删除前检查、与 Emby 通信、删除结果确认）」等；避免「验收轮询」「Flow」等对一般用户生僻的组合。

### 4.3 任务中心 · 执行日志（默认展示）

- **默认行格式**：时间戳 + **中文**叙事句；语气为「发生了什么」，而非调试码。
- **机器可读 `code`**（如 `delete.precheck.start`）：默认**不**与主句并列展示；若保留排障能力，置于折叠「技术详情」或全局「显示技术详情」开启后展示。
- **日志正文**：避免英文状态名 `executing`、裸 API 名作为主语；若必须提及，放在技术详情或括号内简短补充。
- **持久化**：日志仍可按现有结构存储；仅**展示层**遵守本条。

### 4.4 媒体库管理 · 删除档说明

- **禁止**「详见仓库 `docs/design/...` §x.x」；改为应用内步骤说明（任务中心 → 信息确认 → 等）。

### 4.5 海报墙 · 确认已观看

- 主按钮避免单独使用「回写」；推荐 **「同步为已在 Emby 标记已观看」** 或 **「标记为已观看并同步」**（实现择一并全端统一）。

### 4.6 配置中心 · Emby 与播放器

- 「启动参数模板」→ 推荐 **「播放器命令行参数」**（或等价清晰短语）。
- 「已播放阈值(%)」→ 推荐 **「视为已看完的最低进度（%）」**。
- 密码/令牌说明：减少冷术语堆叠；强调**用途**（如以你的账号执行删除等），**AccessToken** 等若出现须简短释义或下移小字。

### 4.7 删除 · 信息确认

- 「DeleteInfo 路径」→ **「将涉及的文件路径（节选）」** 或 **「Emby 返回的待删除路径（节选）」**。

### 4.8 任务卡片 · 转码体积摘要

- 「按规则不采纳」→ **「体积未减小，未替换原文件」** 或等价直白句。

### 4.9 转码确认弹窗（杜比视界 / 替换前确认）

- **首句**：结论与风险的人话概述。
- **术语**（partial、replace、libplacebo 等）：放入 **「技术细节」** 折叠或次要段落，避免首屏堆砌。

## 5. Electron / 服务层与 UI 同源错误

- 凡可能通过 `setError`、对话框等展示给用户的 `Error.message`：**中文主句** + 可选 **可操作指引**（如「请到配置中心 → 任务中心检查转码设置」）。
- **媒体管理服务不可达**（壳层门禁、配置保存被拒绝）：须 **中文**说明须先启动或连接本机媒体管理服务，避免暗示「仅缺 Emby」；不要求用户阅读仓库路径；详见 `[DESIGN_DESKTOP_MEDIA_SERVICE_AVAILABILITY.md](./DESIGN_DESKTOP_MEDIA_SERVICE_AVAILABILITY.md)` 与 `[DESIGN_CONFIG_CENTER_SAVE_FEEDBACK.md](./DESIGN_CONFIG_CENTER_SAVE_FEEDBACK.md)` 第 8.1 节。
- **禁止**在消息字符串中使用 `§` 或「任务中心 · 转码 Flow · §7.4」类文档定位。
- 主要实现入口示例：`[media-desktop/electron/transcodeService.js](../../media-desktop/electron/transcodeService.js)`、`[media-desktop/src/App.tsx](../../media-desktop/src/App.tsx)` 中错误透传；与 `media-service` 同源错误字符串若也会到达桌面 UI，应同样遵守。
