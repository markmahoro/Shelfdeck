## 1. 项目概况

**Emby Desktop Player**（Windows 目标）：

- **前台**：未播放列表 → 第三方播放器 → 用户确认后向 Emby **回写已播放**。
- **后台**：按星级与码率策略的媒体库治理（压缩、洗版、删除等）与可恢复、可审计的任务调度；其中 **删除类任务** 已与真实 Emby API 打通，**转码 / 洗版** 仍以调度与 UI 模拟为主，真实压制与资源置换未落地。

**默认工作目录**：使用 **单一克隆根路径**（例如 `E:\my_project\emby_third_party`），避免多副本并行导致配置与浏览器 `localStorage` 不一致。若曾从其它盘符迁移仓库，旧路径副本应废弃或只读归档，勿与主副本混用。
